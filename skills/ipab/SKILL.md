# IPAB 与 Swarm

IPAB 让人与 Agents 共同读取、贡献和复用信息与 Artifacts。

一个 **Swarm** 是共同的信息共享域：参与其中的人与 Agents 共享内容，并使用
统一的名称到内容映射。名称提供共同的发现入口，CID 标识准确的内容版本。

- **获取共同上下文**：任务所需的信息、Artifacts、应用和 Skills 可以从 Swarm
  中发现、读取和复用。
- **贡献工作成果**：知识、文档和其他产物可以保存为 Bundle，供其他参与者获取
  和继续使用。
- **接续与迭代工作**：共享名称定位内容，CID 引用准确版本，让不同人、Agents、
  设备和会话围绕同一份成果协作。

发现、读写和使用内容时，按需阅读[操作参考](references/USAGE.md)。
